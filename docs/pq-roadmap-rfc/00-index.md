## Scope Note
This document bundle describes direction, decision framework, and validation paths.
It is not an implementation or delivery plan.

## Reading Categories
The RFC uses two chapter categories:
- `Informative`: primarily written for non-technical readers and broader orientation.
- `Formal`: primarily written for technical and governance decision audiences.

This categorization is a reading aid, not an access barrier. Non-technical readers are explicitly encouraged to read formal chapters as well.
